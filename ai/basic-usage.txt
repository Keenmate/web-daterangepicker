BASIC DATE PICKER USAGE
========================

TWO USAGE MODES
---------------
1. Web Component (HTML attributes)
2. JavaScript API (programmatic control)

CRITICAL: Most callbacks are available as web component PROPERTIES:
- renderSummaryCallback - custom summary rendering (WEB COMPONENT PROPERTY)
- getDateMetadataCallback - dynamic date metadata (WEB COMPONENT PROPERTY)
- getBadgeTooltipCallback - custom badge tooltips (WEB COMPONENT PROPERTY)
- getDayTooltipCallback - custom day tooltips (WEB COMPONENT PROPERTY)
- renderDayCallback - custom day rendering (WEB COMPONENT PROPERTY)
- renderDayContentCallback - custom day content (WEB COMPONENT PROPERTY)
- getCustomStylesCallback - inject custom styles to shadow DOM (WEB COMPONENT PROPERTY)
- beforeSelectCallback - validation callback (WEB COMPONENT PROPERTY)
- beforeMonthChangeCallback / getMonthDataCallback - navigation gate + bulk month data
- beforeActionCallback - gate every action button click

Every callback receives ONE context object (ctx) carrying ctx.controller (the
public facade, same as el.controller), ctx.element (the host) and the
presentation flags, plus its own fields.

Property-only (no attribute):
- labels - custom UI button labels
- actionButtons - custom button configuration

WEB COMPONENT (Simple HTML)
----------------------------
Include the script, use the tag:

<script type="module" src="https://unpkg.com/@keenmate/web-daterangepicker"></script>

<web-daterangepicker
  selection-mode="single"
  placeholder="Select a date">
</web-daterangepicker>

Auto-registers as custom element.
No JavaScript needed for basic usage.

WEB COMPONENT ATTRIBUTES
-------------------------
All kebab-case, string values:

<web-daterangepicker
  selection-mode="range"
  visible-month-count="2"
  min-date="2025-01-01"
  max-date="2025-12-31"
  disabled-weekdays="0,6"
  date-format-mask="YYYY-MM-DD"
  placeholder="Select dates"
  locale="en"
  positioning-mode="floating"
  calendar-placement="bottom-start"
  show-today-button="true"
  show-clear-button="true"
  commit-mode="selection">
</web-daterangepicker>

WEB COMPONENT CALLBACKS (Properties, Not Attributes)
------------------------------------------------------
Callbacks CANNOT be set via HTML attributes. Set them as JavaScript properties:

<web-daterangepicker id="my-picker" selection-mode="range"></web-daterangepicker>

<script>
  const picker = document.getElementById('my-picker');

  // Custom summary rendering
  picker.renderSummaryCallback = (data) => {
    const total = data.nights * 150;
    return `${data.nights} nights × $150 = $${total}`;
  };

  // Custom date metadata
  picker.getDateMetadataCallback = ({ date }) => {
    if (isHoliday(date)) {
      return {
        isDisabled: true,
        badgeText: '🎉',
        badgeClass: 'holiday'
      };
    }
    return null;
  };

  // Custom tooltips
  picker.getDayTooltipCallback = (data) => {
    return `Click to select ${data.date.toLocaleDateString()}`;
  };

  // Custom rendering
  picker.renderDayContentCallback = (data) => {
    const div = document.createElement('div');
    div.textContent = data.dayNumber;
    if (data.isWeekend) {
      div.style.color = 'blue';
    }
    return div;
  };

  // Custom styles injected to shadow DOM
  picker.getCustomStylesCallback = (ctx) => `
    .drp__day--weekend {
      background-color: #f0f9ff;
    }
  `;

  // Validation before selection
  // Return nothing = accept, false = reject, Date/DateRange = adjust, null = clear
  picker.beforeSelectCallback = async (ctx) => {
    const isAvailable = await checkAvailability(ctx.range ?? ctx.date);
    if (!isAvailable) {
      ctx.controller.showMessage('Dates not available', { type: 'error' });
      return false;
    }
  };
</script>

Callbacks are reactive properties — they can be set before or after the
element upgrades/connects. To avoid an upgrade-then-restyle flash, add the
`defer` attribute, wire everything, then call el.release().

JAVASCRIPT API (Full Control)
------------------------------
Import and instantiate:

import { DateRangePickerEngine } from '@keenmate/web-daterangepicker';

const inputElement = document.querySelector('#my-input');
const picker = new DateRangePickerEngine(inputElement, {
  selectionMode: 'single',
  minDate: '2025-01-01',
  maxDate: '2025-12-31',
  dateFormatMask: 'YYYY-MM-DD',
  onChange: (detail) => {
    console.log('Selected:', detail.date, detail.formattedValue);
  }
});

Note: JavaScript API uses camelCase property names.

SINGLE DATE MODE (default)
---------------------------
Select one date:

<!-- Web Component -->
<web-daterangepicker
  selection-mode="single"
  placeholder="Pick a date">
</web-daterangepicker>

// JavaScript API
const picker = new DateRangePickerEngine(input, {
  selectionMode: 'single',
  onChange: (detail) => {
    console.log('Date:', detail.date); // Date object
  }
});

Event: change
Event detail: { date: Date, formattedValue: "2025-01-15" }

RANGE MODE
----------
Select start and end dates:

<!-- Web Component -->
<web-daterangepicker
  selection-mode="range"
  visible-month-count="2"
  placeholder="Select date range">
</web-daterangepicker>

// JavaScript API
const picker = new DateRangePickerEngine(input, {
  selectionMode: 'range',
  visibleMonthCount: 2,
  onChange: (detail) => {
    console.log('Start:', detail.dateRange.start);
    console.log('End:', detail.dateRange.end);
  }
});

Event: change
Event detail: { dateRange: { start: Date, end: Date }, formattedValue: "..." }

MULTIPLE MODE
-------------
Select multiple individual dates or ranges:

<web-daterangepicker
  selection-mode="multiple"
  positioning-mode="inline"
  visible-month-count="2">
</web-daterangepicker>

Access selections:
const dates = picker.selectedDates;    // Array of Date objects
const ranges = picker.selectedRanges;  // Array of { start, end } — range mode: always the
                                       // selection ([{start,end}] for a plain range, every
                                       // piece for independent/split ranges, [] when empty)

INLINE MODE (Always Visible)
-----------------------------
Calendar embedded in page, always open:

<web-daterangepicker
  positioning-mode="inline"
  selection-mode="range"
  visible-month-count="2">
</web-daterangepicker>

Use cases:
- Dashboard widgets
- Booking interfaces
- Date browsing tools

FLOATING MODE (Dropdown - default)
-----------------------------------
Calendar opens on click:

<web-daterangepicker
  positioning-mode="floating"
  calendar-placement="bottom-start"
  selection-mode="single">
</web-daterangepicker>

Placement options:
- bottom, bottom-start, bottom-end
- top, top-start, top-end
- left, right

Auto-adjusts with Floating UI if viewport constrained.

LISTENING TO EVENTS
--------------------
Web Component fires custom events:

const picker = document.querySelector('web-daterangepicker');

// Primary event (use this)
picker.addEventListener('change', (event) => {
  console.log('Selected:', event.detail);

  if (event.detail.date) {
    // Single mode
    console.log('Date:', event.detail.date);
  } else if (event.detail.dateRange) {
    // Range mode
    console.log('Range:', event.detail.dateRange);
  }
});

// Or the on* twin — receives the DETAIL, not the event
picker.onChange = (detail) => console.log(detail.date ?? detail.dateRange);

Other events: 'open' / 'close' (the popover), 'action' (action buttons / data-action triggers),
'month-change' ({ monthIndex, year, month, visibleMonths }),
'ready' ({ controller, element }). See events-callbacks.txt.

ACCESSING VIA JAVASCRIPT
-------------------------
The element itself is the API; `el.controller` is the stable facade (the same
object callbacks get as ctx.controller). There is no `el.picker`.

<web-daterangepicker id="my-picker"></web-daterangepicker>

<script>
const el = document.getElementById('my-picker');

// Element properties
const startDate = el.selectedStartDate;
const endDate = el.selectedEndDate;

// Controller facade
const range = el.controller.selectedRanges[0];
el.controller.clearSelection();
el.controller.showMessage('Saved', { type: 'success', autoHideMs: 2000 });
</script>

SETTING PROPERTIES PROGRAMMATICALLY
------------------------------------
Web component exposes reactive properties:

const picker = document.querySelector('web-daterangepicker');

// Set selected range
picker.selectedRanges = [
  { start: new Date('2025-01-01'), end: new Date('2025-01-31') }
];

// Open/close calendar
picker.isOpen = true;

// Set callbacks (if exposed)
picker.getDateMetadataCallback = ({ date }) => {
  const isWeekend = date.getDay() === 0 || date.getDay() === 6;
  return isWeekend ? { isDisabled: true } : null; // Disable weekends
};

// or decorate every day
picker.getDateMetadataCallback = ({ date }) => {
  return {
    badgeText: '✓',
    dayClass: 'special',
    isDisabled: false
  };
};

EXTERNAL CONTROL BUTTONS
-------------------------
Control picker from outside:

<button onclick="setToday()">Today</button>
<button onclick="setLastWeek()">Last Week</button>
<web-daterangepicker id="external-picker" selection-mode="range"></web-daterangepicker>

<script>
const picker = document.getElementById('external-picker');

function setToday() {
  const today = new Date();
  picker.selectedRanges = [{ start: today, end: today }];
}

function setLastWeek() {
  const end = new Date();
  const start = new Date();
  start.setDate(end.getDate() - 7);
  picker.selectedRanges = [{ start, end }];
}
</script>

SIZING
------
Use size attributes directly on the web component:

<web-daterangepicker
  input-size="lg"
  spacing="lg"
  font-size="lg"
  cell-size="lg">
</web-daterangepicker>

Available size values (consistent across all): xs, sm, md (default), lg, xl

Size attributes:
- input-size: Input field size (floating mode only)
- spacing: Calendar spacing scale
- font-size: Calendar font size scale
- cell-size: Calendar day cell size

Example - compact picker:
<web-daterangepicker input-size="sm" spacing="sm" font-size="sm" cell-size="sm">
</web-daterangepicker>

Example - large picker:
<web-daterangepicker input-size="xl" spacing="lg" font-size="lg" cell-size="lg">
</web-daterangepicker>

CSS classes also available for calendar (applied internally):
- Font: drp-font-xs, drp-font-sm, drp-font-md, drp-font-lg, drp-font-xl
- Spacing: drp-spacing-xs, drp-spacing-sm, drp-spacing-md, drp-spacing-lg, drp-spacing-xl
- Cell: drp-cell-xs, drp-cell-sm, drp-cell-md, drp-cell-lg, drp-cell-xl

LABELS (i18n)
-------------
All UI strings come from ONE `labels` object — partial, English defaults
(exported as DEFAULT_LABELS). No built-in translations. Month / weekday names
come from Intl for `locale` (auto = browser language) or monthNames/weekdayNames.

<web-daterangepicker selection-mode="range" locale="de"
  labels='{"today":"Heute","clear":"Löschen","apply":"Übernehmen","days":"{count} Tage","nights":"{count} Nächte"}'>
</web-daterangepicker>

el.labels = { today: 'Dnes', days: '{count} dní', fullscreenTitle: 'Vyberte termín' };

Keys: today, clear, apply, now, close, preview, day, days, night, nights,
selectionCount ({count}), time, am, pm, hours, minutes, seconds, fullscreenTitle.
'' = deliberately empty (renders nothing); undefined / missing = English default.
Content labels (preview, day(s), night(s), time, hours, minutes, seconds, am/pm in
the time pickers) are inserted as HTML; {count} is escaped; the rest are plain text.
❌ customStrings, fullscreen-title  → ✅ labels / labels.fullscreenTitle

LIFECYCLE
---------
<web-daterangepicker defer>  → nothing builds until el.release() (or removing
`defer`); then the `ready` event, the `ready` attribute, :state(ready),
el.isReady / await el.whenReady(). el.destroy() tears it down for good.
❌ el.ready(), is-ready  → ✅ el.release(), ready
