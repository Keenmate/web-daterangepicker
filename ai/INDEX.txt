ERROR PATTERNS TO AVOID
-----------------------
❌ setting callbacks as HTML attributes → basic-usage.txt (use JS properties)
❌ labels / actionButtons as HTML attributes → set them as properties
❌ el.picker / ctx.picker (removed) → use el.controller / ctx.controller / ctx.element
❌ e.detail inside on* twins → el.onChange = (detail) => detail.date
❌ { action: 'custom', ... } buttons → { id: 'my-id', ... }
❌ { action: 'accept' } result objects → return nothing / false / a value (events-callbacks.txt)
