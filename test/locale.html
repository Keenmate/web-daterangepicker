locale & i18n

Targeted by e2e/locale.spec.ts.

explicit locale="de" — German month + weekday names
labels overrides only the Today button label
monthNames override — uses numeric labels
week-start-day="0" — Sunday is first weekday column
week-start-day="1" — Monday is first weekday column
month-names attribute (pipe-delimited Czech) — June → "Červen"
weekday-names attribute (Sunday-first Czech) + week-start-day="0" — first column "Ne"
weekday-names (Sunday-first) + week-start-day="3" — Wednesday-first, first column "St"
weekday-names with wrong segment count — ignored, falls back to locale (Su…)
labels JSON attribute — {count} placeholders
locale="auto" week-start-day="auto" — follows the browser (navigator.language)
