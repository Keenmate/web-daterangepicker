selection modes

Targeted by e2e/selection-modes.spec.ts. Each picker is pinned to initial-date="2026-06-15" so day cells are deterministic across machines / timezones / runs.

single — selects one date, no Apply button
range — two clicks define a range
multiple — toggles individual days, requires Apply
range with commit-mode="apply" — defers commit until Apply, Escape restores prior value
single with commit-mode="manual" — a pick only stages (no close, nothing written)
range with commit-mode="manual" — the app commits via a custom "Done" button (controller.apply())
booking.com flow — commit-mode="selection" should-close-on-select="false": written on every pick, stays open
single, should-close-on-outside-click="false"
range, commit-mode="manual" should-close-on-outside-click="true"
