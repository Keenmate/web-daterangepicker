page-wide locale

Targeted by e2e/page-locale.spec.ts. The page sets window.components.locale = { locale: 'cs-CZ' } before the component loads (core /locale).

no locale attribute — follows the page (cs-CZ: Czech names, Monday first)
locale="en-US" — the instance wins over the page (English, Sunday first)
locale="auto" — the same as unset: follows the page (cs-CZ)
labels='{"buttons.today":"Mine"}' — the instance labels win over the page-wide labels, key by key
selection-mode="multiple" — the input shows labels.selectionCount ({count} as a number)
selection-mode="range" — a custom renderSummaryCallback reads ctx.labels.text() / .html() (core createLabelsView)
